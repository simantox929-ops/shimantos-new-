# Simanto Shanal - Interactive 3D Portfolio (Stormy Edition)

An interactive three-dimensional personal portfolio website built for an Electrical & Electronic Engineering (EEE) student featuring a dark stormy atmosphere and dynamic lightning strike animations on a 3D rotating cube.

## Features
- **3D Stormy Environment:** Built using Three.js with realistic rotating 3D elements.
- **Dynamic Lightning Strikes:** Automated lightning bolts striking the central cube with background flash overlays.
- **Modern Tech Stack:** HTML5, Tailwind CSS, JavaScript (ES6+), and Three.js.
- **Complete Sections:** About, Skills, Projects, Certificates, Gallery, and Contact.
